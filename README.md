# JS Snacks Functions

## 📌 Descrizione
Una raccolta di mini-esercizi (snack) focalizzati sull'utilizzo delle funzioni in JavaScript. L'obiettivo è risolvere piccoli problemi logici attraverso la scomposizione del codice in blocchi riutilizzabili e indipendenti.

## 🎯 Obiettivo
Esercitarsi nella definizione e nell'invocazione di funzioni, passando parametri e gestendo i valori di ritorno (return).

### Focus Tecnico:
- **Definizione di Funzioni:** Creazione di logiche specifiche per ogni snack richiesto.
- **Parametri e Return:** Gestione corretta dei dati in ingresso e dei risultati in uscita dalle funzioni.
- **Invocazione:** Chiamata delle funzioni con diversi set di dati per verificarne la robustezza.
- **Refactoring (Bonus):** Sperimentazione con la sintassi delle **Arrow Functions** per rendere il codice più sintetico e moderno.

## 🛠️ Tecnologie Utilizzate
- **HTML5:** File di supporto per l'esecuzione degli script.
- **JavaScript (ES6+):** Utilizzo di *Function Declarations* e *Arrow Functions*.
